使用条款

OfficeAgent 是由 kinfey 提供的办公协作助手。使用前，请同时阅读本条款、隐私声明，以及你所在组织适用的政策。

1. 使用资格与授权

你必须有权处理提交的数据，并取得组织要求的许可。个人版需要本人个人 Microsoft 账号授权、本机桥接及可用的 Foundry 服务；Teams 安装仍受组织应用策略约束。企业 Autopilot 版还需要相应 Microsoft 365、Agent 365 与 Work IQ 条件、管理员审批及最小必要委派。

蓝图发布、工具可用或助手拥有邮箱，不代表它可以访问其他人的数据。不得使用助手规避租户策略、冒用身份、扩大权限或处理你无权访问的信息。

2. 人工确认规则

邮件发送及会议创建、修改、取消均需先有完整预览，再由配置本人在原私聊或本机终端会话中发出有效确认。确认之前，请核实全部收件人、主题、正文、时间、时区、参会人和目标日历。

个人版邮件以你本人身份发送；企业 Autopilot 邮件由助手自身邮箱发送。不要把“已经准备提案”理解为“已经执行”，也不要把“服务已接受”理解为“收件人已经收到”。遇到结果未知时，请先人工核实，避免重复发送或重复邀请。

3. 功能与 AI 限制

服务可能产生错误、不完整或过时的输出。摘要、草稿、候选时段和来源链接都需要适当复核；对来源中的命令或未经核实的事实保持警惕。

助手不是法律、医疗、财务或安全决策的专业替代品，不应被用于必须依赖确定性、无中断运行的高风险场景。当前版本不承诺处理所有邮件、所有日历或所有会议类型。

4. 组织与用户的责任

组织负责配置身份、委派、内容权限、支出策略、数据保留和审计，并指定可负责的经理。用户负责仅提交有权处理的信息，审阅拟执行的动作，以及报告异常。

不要在公开支持渠道提交个人信息、内部资料、凭据或访问令牌。发现异常时，应停止批准操作并联系组织管理员。

5. 可用性、费用与停止使用

服务依赖第三方平台和组织配置，可能因维护、策略、许可证、额度或权限而不可用。本说明不作持续可用、特定结果或无错误运行的承诺。

使用可能产生模型、Work IQ、托管和许可证费用，按组织与相应服务商的约定结算。本支持网站不代你购买或开通任何收费服务。

若不接受这些条件，请停止使用。个人版可关闭本机桥接、卸载 Teams 应用并撤销个人账号应用同意；企业版可由组织管理员撤销委派、禁用实例或蓝图并处理保留数据。停用不等于所有服务中的记录立即删除。

6. 第三方服务与变更

Microsoft 与 GitHub 等服务分别适用其自身条款。本项目不是 Microsoft 官方产品，不代表其提供额外保证；本条款不限制任何适用法律所赋予、不得排除的权利。

功能和条款可能随版本更新。发布者与组织应在部署重要变更前重新审阅，必要时完成新的通知与审批。

7. 联系

一般问题请参阅 支持页面；组织数据、授权、删除及安全事件请通过组织内部渠道联系管理员。
